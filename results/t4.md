# T4: Conducted CW Jammer, Power Inversion

Plan: `docs/t4_plan.md`. Status: **in progress** (2026-11-11). Done: P1 to P3
in V1; P3, the null run N, the fixed-weight run F and the PI run P in V3
(V3-P on 2026-11-11, with P3 repeated before it).

Unit: second Pluto (CRPA unit, serial `1044734c96050011f2ff2100408f4f2ac3`),
`fw_version` v0.39-22-g8f9c-dirty. Delta +3 MHz, fs 10 MSPS, bw 9 MHz, RX gain
60 dB manual on both, INT_LEN 10000, OUT_SHIFT 0. No Pluto transmission in
P1 to P3 and N: TX LO powered down and TX attenuation 89.75 / 89.75 dB, read
back at the start and end of every capture set.

Cabling as stated by the user: bladeRF (`./bladegps -e brdc3300.18n`, TX gain
17 dB) -> 40 dB -> SPL1 -> CMB1 / CMB2 -> RX1 / RX2; B205mini `TX/RX` ->

u-blox. V1: both jammer legs as first cabled (the leg to CMB1 is 25 cm). V3:
the jammer leg to CMB1 (RX1) is a 50 cm cable.
